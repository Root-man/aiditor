Rules
Every saved project is listed; those with no workspace come last, by name. It opens with projects unfolded, workspaces folded, the current one open. A folded row sums up what it hides; an open project leaves that to its rows. Colour only for state, in the mode lines' colours and words. Yellow marks the workspace you are in; the band marks the row you are on. Blank rows follow open projects, so folded ones sit together. Point stops on project and workspace rows only; buffer rows stay informational.
